# docs/guides/ —— 用户操作手册专区

本目录**只放直接交给内容贡献者的实操说明书**（GUIDE_<域>.md 一族）：
流程步骤 + 配方卡 + 常见病处方，读者不需要打开代码编辑器。

| 手册 | 管什么 |
|---|---|
| `GUIDE_关卡搭建.md` | 壳/段双轨搭章节、互动件摆放、验收三件套、零件库 |
| `GUIDE_格挡.md` | 格挡/弹反时序平衡、格挡动画换图与帧轨纪律 |
| `GUIDE_光照.md` | 昼夜数据、阴影区域、软边（原 LIGHTING_SETUP_GUIDE，2026-09-28 收编改名） |

## 维护规则（与 M3 可生产性铁律配套）

1. **每批交付新内容能力，工程侧必须在本目录登记/更新对应 GUIDE**（铁律三件之一）；
2. 手册=操作导向，法律条款/红线原文一律**指针引用法典**（STAGE_ASSEMBLY 等），
   不复制正文——防两处真相漂移；
3. 法典、源码分析、设计案卷、历史 PLAN/spike/specs 留在 `docs/` 原位，
   **不得混入本目录**（读者不同）；
4. 改名/迁居本目录文件时，活文档互链同批改（历史案卷不回改）。
