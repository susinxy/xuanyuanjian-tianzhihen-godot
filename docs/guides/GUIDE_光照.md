# GUIDE_光照 —— 昼夜与阴影的搭建说明书

> 谁该看：想让章节有白天/黑夜变化、或调整阴影效果的内容贡献者。
> 不需要写任何代码；不懂的词查 `术语表.md`。
> 现状基线：2026-10 文档整改批按壳+段新制重写（旧版还在讲已退役的单地点骨架）。

## 0. 你多半什么都不用做

每章的壳文件（`chapter_shell.tscn` 另存来的）里已经预置好一切：

- **白天默认生效**：什么都不设 = 一直是普通白天（画面正常、阴影正常）；
- 想要昼夜变化 → 挂一份时间数据（第 2 节，两次点击的事）；
- 想要阴影只在场地内 → 摆一个框（第 3 节，可选）。

## 1. 光照系统三层各在哪

| 层 | 是什么 | 谁管 |
|---|---|---|
| 全局 | 昼夜调度器、软边阴影合成器（游戏自动启动时常驻） | 工程侧，你不用碰 |
| 角色阴影 | 每个人物脚下的椭圆阴影，随太阳角度转向 | 全自动 |
| 场景昼夜 | 壳里 `Ambient/` 三件套：画面色调（CanvasModulate）+ 方向光（KeyLight）+ 昼夜控制器（DayNightController） | **你只挂一份数据文件给它** |

## 2. 想有昼夜：挂时间数据（就一件事）

选中壳根 → `Ambient/DayNightController` → Inspector 的 `scene_time_data` 拖一份进去。

现成文件在 `resources/lighting/`：

| 文件 | 效果 | 适用 |
|---|---|---|
| （留空） | 无昼夜，一直正常白昼 | 不挑时间的章 |
| `day_cycle_default.tres` | 完整昼夜循环（约 5 分钟一圈：拂晓→白天→黄昏→夜晚） | 正式章节 |
| `day_cycle_demo.tres` | 60 秒快进版 | 测试/预览用 |
| `day_neutral.tres` | 恒定正午 | 想要"有控制器但天色不动" |

配套知识：

- **每一段的入场天色**可以不同：段根有个 `lighting_color`（颜色），比如"这段是黄昏回忆"。
- 想自定义时间曲线：复制一份起步 `.tres` 改四个相位的颜色/仰角即可。
- 活教材：`scenes/stages/ref/chapter_ref_a.tscn`（不挂数据=白天）和 `chapter_ref_b.tscn`（挂 60 秒演示=能看到天色变）——各按 F6 跑一遍就懂。
- 正式关卡想快速验昼夜效果：不必重跑，按 `=` 打开调试面板，"光照"页有相位按钮和倍速。

## 3. 阴影

- **柔化阴影（软边）默认开启**。按 **L** 可在硬边/软边之间切换对比——纯调试，不改存档行为。
- 想让阴影只出现在场地内（更好看也更省性能）：段里加一个 ReferenceRect，
  附加脚本 `scripts/shadow_region.gd`，拖框盖住可行走地面。
  规则：**0 个框 = 全场都有阴影；多个框 = 取并集；框不许重叠**（重叠处会双倍变暗）。
  参考实例：`scenes/stages/ref/seg_ref_b1.tscn` 里的一整块战区框。
- 阴影的"压底层次"已自动摆好（在所有背景之上、场景内容之下），无需设置。
  只有一种例外需求（比如你要放一张"盖在世界上但压在阴影下"的特殊裸图层）——
  那时才用壳根的 `shadow_composite_override` 数值覆写（保持默认值 = 自动档，别动它）。
  这种需求很少见，遇到了找工程侧一起定。

## 4. 两条禁令（做背景/灯光时别踩）

1. **KeyLight 的 `shadow_enabled` 永远保持不勾选**。人物阴影由专门的阴影系统画；
   勾上会出双影+性能跳水。（壳模板里预置已关，别手贱重开。）
2. **背景图层的 layer 必须是负数**（如 -1；纯 debug 背景用 -10）。
   写了 0 或正数 = 背景把角色和阴影整个盖住（校验器 R10 也会拦）。

## 5. 剧情临时光效（工程侧通道，了解即可）

剧情里要"瞬间压暗/圣光一闪"这类效果，走全局昼夜管理器的临时覆盖接口
（`DayNightManager.apply_lighting_override(数据, 秒数)`，到时自动还原）。
接线属工程批（B7 过场链的一部分）。注意：临时光效经由场景控制器生效，
**壳至少要挂一份时间数据（哪怕 `day_neutral`），否则控制器休眠不接单**。

## 6. 调试面速查

| 键 | 作用 |
|---|---|
| `=` 或 `+` | 打开/关闭调试面板（正式章默认关） |
| 面板"光照"页 | 四相位按钮、循环倍速（1×/4×/16×/暂停）、临时光效演示、阴影调试线开关 |
| 5 / 6 / 7 / 8 | 直接切 拂晓/白天/黄昏/夜晚 |
| L | 软边阴影 开/关 对比 |
| T | 阴影区域框可视化（有 ShadowRegion 时） |

## 7. 常见病

| 症状 | 原因 | 处置 |
|---|---|---|
| 挂了数据天色也不变 | 挂错了节点（要给 `Ambient/DayNightController` 挂，不是壳根）；或数据是 `day_neutral`（恒定档本来就不变） | 对照第 2 节；换 `day_cycle_demo` 试 |
| 整个画面发暗/发灰回不来 | 别的场景把昼夜管理器留在了覆盖状态 | 重进关卡；反复出现报工程侧 |
| 脚下两个阴影 | KeyLight 勾了 `shadow_enabled` | 取消勾选（禁令 1） |
| 角色被背景盖住 | 背景 layer ≥ 0 | 改负数（禁令 2） |
| 阴影框重叠处发黑 | 两个 ShadowRegion 交叠 | 挪框或合并成一个 |
