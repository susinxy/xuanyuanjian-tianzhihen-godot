# GUIDE_法术 —— 内容生产者手册

> 给不开代码编辑器的你：从**造一个法术**到**玩家按 1 号键放出来**，全程四步。
> 本手册只教操作。想知道引擎内部原理（存档数据结构、施法流程细节）的，
> 让工程侧查 `docs/superpowers/specs/` 里的法术设计文档和
> `docs/PLUGIN_ARCHITECTURE.md` 法术段。

## 〇、一页总览

| 步 | 你做什么 | 入口 |
|---|---|---|
| 1 造 | 面板表单填一遍，产出一套法术文件 | `templates/spell/spell_template.tscn` → 选根 → Inspector |
| 2 摆 | 段里放一个"秘籍"触发件，填 `spell_id` | 场景编辑器（见 §三 配方卡） |
| 3 学 | 玩家走近按 E（一次性，学会即消失） | 游戏内 |
| 4 放 | 数字键 **1 / 2 / 3 / 4** 对应四个槽 | 游戏内 |

**装配规则（2026-10-09 决定）**：新存档一个法术都不会——所有法术都靠段里摆的秘籍拾得。
每个正式章的**早期段必须至少摆一本秘籍**，否则玩家全程无技可放。结构范例可抄：
`tools/spell_save_contract/fixtures/seg_b4_manual.tscn`。

## 一、造法术（面板五区）

1. 编辑器打开 `templates/spell/spell_template.tscn`，选中根节点 `SpellTemplate`；
2. Inspector 找 **"✨ Create New Spell"** 表单，填三件身份：
   - **English Name**（蛇形，如 `fire_ball`）——同时是目录名与 `spell_id`；
   - **Class Name**（自动生成 PascalCase，可改）；
   - **Display Name**（如 `火球术`，进 HUD tooltip）；
3. 出生数值区（默认值=演示件搬运，按需改）+ **"⚔ 弹体命中数据"** 区（伤害/上中身位/击退/角度）——逐项语义见 §二两张表；
4. 校验过（变绿 ✅）后按 **Create Spell ▶**；
5. **造完必自查两条**（都是真实发生过的事故）：
   - 打开 `spells/<id>/<id>.tscn`，确认定义件 `spells/<id>/resources/<id>_definition.tres` 的 **`spell_scene` 已指回这个 .tscn**（面板自动生成的自带接线；历史上第一颗火球就缺这一行，施法当场崩溃）；
   - **"🧪 Test Spell"** 区选角色×法术按 **Run Test ▶**，能放出、能命中、按 ESC 退出=产线活。

**删除区**：下拉选法术按 Delete（连目录整删，账不清——删件前想清楚）。

**产件清单**（创建器自动生成，路径是硬约定）：
```
spells/<id>/
├── <id>.tscn                  ← 弹体主场景（definition.spell_scene 指它）
├── <id>_skin.tscn/.gd         ← 皮肤（美术替图同名覆盖）
├── resources/<id>_definition.tres    ← SpellRegistry 唯一解析点在此
└── resources/attacks/<id>_attack_data.tres  ← 伤害/击退数据
```
> 路径纪律：全项目按 id 找定义只走 `SpellRegistry`（`spells/<id>/resources/<id>_definition.tres` 写死约定），把法术挪出这个路径=秘籍全部教不了，之前学会的也找不回来。

## 二、数值字段表

### definition（14 项，`resources/<id>_definition.tres`）

| 字段 | 默认 | 人话 |
|---|---|---|
| `spell_id` / `display_name` / `description` | 面板填 | 身份三件 |
| `icon` | 无 | HUD 槽图标；**不填也没事**：自动用 right 方向动画的第一帧当图标 |
| `spell_scene` | 面板接 | 弹体场景（缺=施法崩，见 §一自查） |
| `mana_cost` | 0 | 施一次扣多少蓝（扣法见 §四"蓝"） |
| `max_lifetime` | 5.0 秒 | 弹体没人接也活这么久就淡出 |
| `cooldown` | 0 | 该槽独立冷却秒数（HUD 灰色遮罩即读条） |
| `caster_cast_time` | 0 | **引导段时长**：起手动画放完→保持姿势倒数满本值→出手。实际全身僵直≈起手动画长+本值；0=起手播完立刻出手 |
| `release_ratio` | (1.0, 0.6) | 出手点=身体比例：x 身宽倍数（自动取朝向号）、y 身高倍数（0 脚底 1 头顶）。贴地刺 0.0、胸部火球 ≈0.55、头顶落雷 1.2 |
| `fade_in_time` | 0.12 | 出生渐亮窗口，**期间攻击盒物理不存在**（防贴脸秒杀），想出手即判就填 0 |
| `fade_out_time` | 0.2 | 熄灭窗口；弹体皮肤若配了告别动画，就交给动画收尾，这个系统自动熄灭不生效 |
| `allowed_states` | 空 | 白名单（空=不看白名单） |
| `disallowed_states` | Die、Knockout | 黑名单默认已禁倒地位 |

### 弹体命中数据（4 项，产进 `attacks/<id>_attack_data.tres`）

伤害数值、受击身位（上身/中部——决定对方播哪段挨打动画）、击退强度 K（对"击退抗性池"结算，破线才起飞）、击退角度。

## 三、秘籍件配方卡（教学入口，装配三步）

1. 段内实例化 `scenes/chapter/interact_trigger.tscn`（感应盒自带 160×160，摆到玩家必经处）；
2. 选中它 → 添加子节点 → 勾"用脚本" → 选 `scripts/chapter/reactions/interact_spell_book.gd`（`InteractSpellBook`）；
3. 填导出：
   - `spell_id` = 要教的法术（必须已按约定路径存在，validator R12 缺件红）；
   - `manual_id` 一般留空；**同一法术在不同章各摆一本**时才填章前缀（如 `ch1_fireball`）——存档按"拾到哪一本"记账。留空则两本共用一条记录，后摆的那本开局就自动消失（原因见下）。注意：即使分了账，两本都拾也会**被槽位去重拦下**（同一法术只收第一次），一个法术永远只占一个槽。

行为语义：按 E→立刻教给**当前操控的角色**→书本缩小消失。**已经学会过的秘籍再摆，开局会当场自动消失**（宝箱开空还会留在那儿，秘籍学会就永不再现——两类道具规则不同）。存档自动进行，你不用写任何存盘代码；换章/回跳/读档后角色会自动从存档找回法术——**学过的永远在**。

## 四、施放链（按 1 没反应时照着查）

按序八道门，**第一道卡住就整个静默**（不弹提示是现状，排障靠本表）：

| 序 | 门 | 没过去=什么现象 |
|---|---|---|
| 1 | 槽空（没学/学的不是这槽） | 键 1-4 无反应；HUD 槽显数字无图标 |
| 2 | 冷却中 | HUD 槽灰遮罩在退 |
| 3 | **蓝不够** | 静默拒放。现状：蓝**无任何回复渠道**——上限默认 100（角色 `attributes` tres 的 `mana_max` 调），扣了只能等本命重建（死亡/回检查点/读档=满蓝）。别把法术当平A铺，`mana_cost` 要按"一关一管蓝"规划 |
| 4 | 状态门（默认禁 Die/Knockout） | 倒地爬起前放不出=设计 |
| 5 | 正在施法中 | 上一发两段式没走完 |
| 6 | 空中 | 现状地面专属（想空中放=另立项） |

全过→起手动画（**必完整播完**，角色资产 `spell_start`/`spelling` 两动画，角色模板出生自带）→引导倒数→出手：方向在**释放瞬间**读皮肤朝向（四向归一），弹体生在角色同父容器、按 `release_ratio` 偏移，继承施法者阵营（自己不会被自己的球弹脸上）。

## 五、排障速查

| 症状 | 先查 | 处置 |
|---|---|---|
| Run Test 一按就红字崩 | definition 缺 `spell_scene` | 打开 tres 把 spell_scene 指回 `<id>.tscn` |
| 按 1 全程无反应、槽有图标 | 蓝（§四门3）/状态/空中 | 先挪到空旷地面满蓝试；长期方案=调 `mana_cost` 或 `mana_max` |
| 控制台 `SpellRegistry: 法术 X 定义缺件` | 文件不在约定路径 | 用面板重建或把 tres 挪回 `spells/<id>/resources/` |
| 秘籍按 E 没反应 | 触发件形状/旗标门/已学过判重 | validator R11 跑一遍；换没学过的号试 |
| 弹体出生瞬间秒怪 | `fade_in_time`=0 且贴脸 | 默认 0.12 别动，或拉开距离设计 |
| 玩家死了复活法术没了 | 不该发生（存档自动找回） | 有一种正常情况：操控 NPC 期间学的法术——学进的是那个 NPC；换回玩家角色后按存档自动补回。若补回后仍缺，报工程侧 |
