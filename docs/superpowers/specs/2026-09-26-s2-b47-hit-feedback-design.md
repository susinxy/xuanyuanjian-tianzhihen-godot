## 0. 设计基线（既有裁决重申，防未来翻案）

以下两条是**设计目标**，不是缺陷，本专题及后续批次禁止再当 bug 修：

- **受击不位移**：击退≡击飞（统一模型 K vs 抗击池裁决：够破池=起飞，不够=受击硬直原地吃动画）。`launch_vector` 在受击支不消费是设计使然（2026-09-26 用户重申）。
- **HIGH/MID=受击部位档位**（上身头/身），不是"反应强弱"档位；攻击 tres 的 `hurt_type` 配置不存在"轻重倒挂"问题（2026-09-26 用户澄清，controller 前判撤回）。

方向性受击动画的帧数多少属各角色美术规格，不入机制议题。音效维持 B6 排期，本专题不开口。

## 2. 核心原语：单角色时间控制（hit-slow/hit-stop per character）

R2/R3 是同一原语的两种刻度（定格=倍速 0，慢放=倍速 ~0.2），共用一套调度设施。

### 2.1 实现通道（探针先行，T0 立项）

引擎 API 零信任法：动笔前一次性探针问齐——

- P1：`Node.process_custom_speed`（4.3+）对 `_physics_process` 是否生效（决定 `move_and_slide` 位移是否随之慢）；
- P2：是否**级联子节点**（决定角色壳+皮肤+动画树需逐个挂还是一处挂）；
- P3：动画轨是否随之慢（AnimationTree/AnimationPlayer 链路）；
- P4：`process_custom_speed` 与 `process_always`/暂停交互（暂停菜单期间恢复调度是否被冻——恢复计时器宿主必须 PAUSE_ALWAYS 或走 root 不受 pause 影响的通道）。

**备胎通道**（P1-P3 任一不通时）：`AnimationPlayer.speed_scale`（只管动画流速）+ 位移缩放（在 locomotion 消费的 delta 上乘系数）组合；两通道对消费方接口一致，差异封在实现里。

### 2.2 调度器形态：协程 + 代数令牌（2026-09-26 用户提案，分析后采纳，替代原"手抄账本"案）

- 接口不变：`apply_slow(target, rate, duration_ms)`（rate=0 即定格）；
- **每次请求=一条独立协程**（宿主=helper 本体，满速节点）：设速 → `await get_tree().physics_frame` × N → 恢复。多目标并行天然免费，无状态表；
- **数帧的表禁止是被慢者自己的表**（慢放越慢越出不来的经典大坑）；physics_frame"暂停期照响、帧号照走"是 block_parry 探针实证过的本仓库既有语义——不用 `create_timer`（其与暂停关系无判例）；
- 重入=**代数令牌**：helper 持 `{目标实例 id → 请求号}`，新请求号 +1 并开窗；旧协程 await 醒来比对令牌，发现自己过期**静默让位**（绝不抢新协程的恢复笔）；
- 目标中途释放：醒来 `is_instance_valid` 守卫，尸体直接弃笔；令牌条目协程尾清除；
- 协程半途静默报错=目标永久慢（本仓库协程判例）——防线=契约 H 流"命中→生效→恢复"闭环断言（天生为抓此而生）。
- 宿主位置（游戏侧 autoload vs 插件 helper）T1 探针后定夺。

### 2.3 参数治理（数值治理法——2026-09-26 用户裁：逐角色可配）

- 慢放参数入 **`QuiverAttributes` 受管导出对**（攻击者自己的档案，命中时读攻击方两值）：
  - `hit_slow_factor: float = 0.2`——慢放倍率，**1.0=自然不慢**（零分支消亡法，无需禁用旗）；
  - `hit_slow_anim_pct: float = 0.15`——慢放窗口按**该次攻击动画总长的百分比**计（2026-09-26 用户裁：绝对 ms 会让快拳节奏扰动 4 倍于重击；百分比下"相对拉伸=_pct×(1−factor)=常数"，每招咬合深度均匀。业界主流本是权重绝对帧表，本仓采百分比改良并案卷留名）；
  - 实现前置（T1 查证项）：命中收口处取"本次攻击动画长度"路径——attack_data/攻击态谁持动画名、`AnimationLibrary.get_animation(name).length` 可得性；取不到时降级为固定 ms 兜底常量并 push_warning（不崩不静默）；
  - 连带断言腿（H 流）：**慢放不破连段**——攻击输入窗/缓冲经慢放窗口后三连段仍可完整衔接（节奏均匀性的行为锁）；
- 弹反定格帧数升格出魔数：`parry_stun_frames: int = 6`（**防守方数值域**，替代 hurt_box 的 `_PARRY_FREEZE_FRAMES` 常量；绝对帧语义正确——吃招侧硬停奖励不跟百分比；此项若用户否决可退回单一规则常量）；
- 特效参数卡维持 §3.4 的 preset tres 形态；触发面路由（近战/弹体/弹反）只走"是否调用"旗，不得在旗内推导数值（合法路由旗判例）。

## 3. 消费场景改造

### 3.1 普通命中：全局定格退役（R1）

`hit_freeze.tscn` 节点 `freeze_frames = 0`（覆盖导出默认 3；插件 .gd 默认值同批改 0 并注释本裁决）。`apply_damage_value` 内 `HitFreeze.start()` 对 0 天然安全（`start()` 已有 `>0` 守卫）——**普通/格挡伤害流从此不停世界**。

### 3.2 弹反：从全局暂停改单角色定格（R2）

quiver_hurt_box.gd 弹反支：删除 `HitFreeze.start(_PARRY_FREEZE_FRAMES)`，改调调度器 `apply_slow(攻击者角色, 0.0, 防守方.parry_stun_frames 折算毫秒)`；随后 `apply_knockback(counter)` 照常派发（顶退+受击动画不变，白闪三件套视觉两件不变）。效果时序：弹反成→攻击者原地冻 N 帧→冻毕其受击/弹飞动画照常播→玩家全程可动。

**契约手术**：block_parry_contract 中"弹反定格=全世界 paused"断言改写为"攻击者时间控制生效 + 防守方（玩家）输入/状态机活跃"；B3 spec 判例与 PLUGIN_ARCHITECTURE 弹反节同步勘误（记录"当时实现=全局，用户澄清原意=单角色，2026-09-26 改道"）。

### 3.3 近战命中：攻击者慢放（R3）

挂点=HurtBox 常规命中收口（`_handle_hit_box` 非弹反非格挡支，判定后派发）：攻击者非弹体（`hit_box.character_attributes` 来源为角色近战者）时 `apply_slow(攻击者角色, 攻击者.hit_slow_factor, 攻击者.hit_slow_anim_pct × 本次攻击动画总长)`——**逐角色档案值 + 逐招自适应**（调度器接口维持毫秒参数，百分比换算发生在调用方）。敌人命中玩家同路（攻击者=敌人，读敌人自己的两值）。弹体的 `character_attributes` 绑施法者（P6 探针判例）——**弹体命中不得慢放施法者**，触发面按"近战/弹体"区分走 hit_box 来源旗（路由旗合法形制）。

### 3.4 接触点特效（R4，零美术）

- **接触点**=`hit_box.global_position` 与受击盒 `global_position` 的交叠代表点（取两盒连线中点或攻击盒中心投影，T3 定形）；弹体命中同点义。
- **形态两层**（全程序化，无图片文件）：
  1. 火花：`CPUParticles2D` one_shot 爆发 8~20 枚无贴图小方块，发射方向沿"攻击者→受击者"向量散开，重力和衰减走曲线，寿命 0.15~0.3s，播完 `queue_free`；
  2. 闪光：命中瞬间一枚程序画圆片（Polygon2D 圆形或加色混合粒子），`scale 0.3→1.2`+透明度 1→0，2~3 帧短促扩散。
- **风格=参数卡**：`hit_spark_preset.tres`（粒子数/颜色梯度/散布角/初速/重力/闪光尺寸与色）；`QuiverAttackData` 新增 `@export var hit_effect_style: StringName = &"default"`（攻击方声明反馈风格，与 hurt_type/knock_strength 同族；路由枚举零数值推导=合法旗）。预置卡：`default`（白→浅金小散角）、`heavy`（金→橙大散角大闪光）、`fire`（橙红+反向重力火星上浮）；fire_ball 弹体挂 `fire`，重击/后续兵种各取所需。未配置= `default` 兜底，任何攻击命中都有火花。
- **特效器**（新件）：接收 `(接触点, 风格名, 强度)` 实例化两层，挂 Level/Characters 层世界坐标；`enabled` 导出位（R5）关闭时直接早退不实例化。

### 3.5 运行时开关（R5）

- 新 InputMap 动作 `hit_fx_toggle`（建议 F8；**project.godot 触点**——吞改纪律：施工期由 Windows 端在 Project Settings → Input Map 手加，或 Linux 端改动前取"关了"口令）；
- 特效器 `_input`/`_unhandled_input` 按 raw 键判定翻转 `enabled`（headless 判例：合成 InputEventAction 不进 unhandled 流；测试注入走 raw 直投）；
- 时间腿（慢放/定格）与视觉腿（特效）完全独立：关特效不关慢放；
- 调试坞加文字行"命中特效：开/关（F8）"（注册制 `add_text_tab` 或既有页签插行，防开关状态失踪）。

断言组（场景 runner 形制，落盘卫生：套内 scratch 重定向）：

- H 流·慢放：近战命中→攻击者时间控制生效（探针通道可测属性，如 delta 缩放后的位移距离/动画位置推进率）→窗口（=动画长×pct）毕恢复；挥空→不触发；弹体命中→施法者不被慢放；双向性（敌人拳命中玩家→敌人被慢）；**连段不破**（慢放后三连段完整衔接）。
- S 流·定格退役：普通命中帧 `tree.paused == false`（R1 行为锁）；
- P 流·弹反改道：弹反成功后攻击者被冻（其动画/位移停 N 帧）且**玩家状态机活跃可动**（世界不 paused）；
- E 流·特效：命中→接触点附近特效节点出生→短延时后自动清理（计数归零）；弹体命中同样出生；挥空零出生；风格差异化（fire 与 default 参数卡消费可测）；
- K 流·开关：raw F8 注入→`enabled` 翻转；关闭态下命中零特效节点但慢放照常。

## 5. 风险与已知边界

- **慢放×输入手感**：玩家命中瞬间自己慢 12% 动画长（默认 15%×0.8 相对拉伸）——若 F5 判"糊手"，改该角色 `hit_slow_anim_pct`/`hit_slow_factor`（逐角色档案即回退旋钮，1.0=该角色自然豁免、pct=0 关闭），或整体默认值降档；不预设回退，按 F5 裁决。
- **动画信标×慢放**：被慢角色若恰有末帧信标依赖（攻击态等 `skin_animation_finished`），慢放使动画时钟变慢→信标等比延后=行为正确（慢动作的本意），但**定格=倍速 0 时信标永不到来**——弹反定格结束（恢复 1.0）后才走受击动画，顺序上无死锁（定格期间不依赖信标）；T2 契约须锁"弹反冻毕→受击动画正常走完"全链。
- **暂停菜单×调度器**：菜单暂停期间恢复计时冻结还是照跑？定档：调度器宿主 PAUSE_ALWAYS（照跑，毫秒语义用物理帧计数——与 HitFreeze 现行形制一致），避免"弹反瞬间开菜单→攻击者永久罚站"。
- **共享 attributes 判例**：调度器目标=角色 Node 非 attributes，不触碰幻影掉血族（PLUGIN_ARCHITECTURE §2）。
- 弹体攻击盒 `character_attributes` 绑施法者的既有判例（spell_base.gd:74）是 §3.3 触发面区分的依据，不得凭"攻击者归属"直觉简化。
