# S2-M1-B2 互动触发件批 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付通用互动触发件（E 键）+ 船闸/宝箱/跳河 QTE 三个示范用户，并清偿 B1 终审挂账四件（await-self 收口、mark_cleared 落点终裁、段文件 validator 形态、夹具视觉皮肤化）。

**Architecture:** 触发件=Area2D 组件（`InteractTrigger`，一次性/冷却/旗标门语义），反应侧=挂在触发件下的三个小脚本（宝箱/船闸/QTE），全部复用 B1 壳的既有链（`force_advance_current` / `switch_segment` 代际链）。校验器加段/壳模板两判形 + R11 触发件执法。新契约套 `tools/interact_contract/`（矩阵 24→25），既有 `container_contract` 追加 E8/D5 两流。

**Tech Stack:** Godot 4.7 GDScript；契约=场景 runner + 逐物理帧 await + 完成旗防线；子进程 stderr 指纹法（E7 先例）。

**Spec:** `docs/superpowers/specs/2026-09-21-s2-prologue-slice-design.md`（§4 是接口法源；§8 M1 行"B2 触发件批"是验收口径：宝箱/船闸可交互）；开账四件见 `DEVELOPMENT_STATUS.md` M1-B1 终审入账段。

## Global Constraints

- GDScript 4；**注释一律中文**（`#`/`##`）；脚本 `snake_case.gd`、场景 `snake_case.tscn`、节点 `PascalCase`。
- 提交消息中文 `feat: …` / `fix: …` / `docs: …` / `chore: …`；**逐路径点名 git add，永久禁 `git add -A`**（用户 WIP 在旁：`project.godot`、`scenes/stages/xuanyuan-chapter-1/**`）。
- **本批零 addons 触点**（不碰 Quiver 插件 → PLUGIN_ARCHITECTURE 同批义务免除；若施工中冒出插件改动=停下上报，不得顺手）。
- `.tscn` 手工语法纪律：`&"名"` 带引号、`load_steps` = ext+sub 计数、复合属性写全构造式、新文件不写 uid 让编辑器自生。**新增 `class_name` 后先跑一次 `godot --headless --path . --import`** 再跑消费方测试。
- headless 判例（本批全数适用，出处 AGENTS/契约注释）：①`_unhandled_input` 只收**原始按键事件**——契约注入一律 `Input.parse_input_event(InputEventKey)`（physical 匹配、`is_action_pressed` 用**非 exact** 形）；②零宽线对瞬移不触发→检测靠实体矩形+传送后 ≥2 帧；③协程子流报错=静默跳段→每流完成旗；④对象协程 await-self=resume-on-freed 炸点（本批 T1 主题）。
- runtime 视觉（字形/色彩观感）不由 Linux 裁决——**F5 单交用户**（T8 出单）。
- 分层回归：每任务只跑受影响套；**全矩阵 25 套只在 T8 跑一次**。

- [ ] **Step 4: 写 SwitchFlow**

```gdscript
class_name SwitchFlow
extends RefCounted

## 转场链载体（B2-T1，终审 Issue 1）：静默窗/强清/结算的逐帧等待全部发生
## 在 RefCounted 协程里——continuation 由场景树信号自持，壳先亡只触发
## is_instance_id_valid 让位，**不再踩 resume-on-freed**（await-self 判例收口）。
## 时序与旧 _settle_before_switch 逐位等价（T1 红线；mark 后移另案 T2）。

var _shell_id := 0
var _gen := 0

static func start(shell: ChapterShell, gen: int, target: StringName,
		entry: StringName, why: StringName, revive: bool,
		mark_src: StringName) -> void:
	var flow := SwitchFlow.new()
	flow._shell_id = shell.get_instance_id()
	flow._gen = gen
	flow._run(target, entry, why, revive, mark_src)

## 协程宿主=本 RefCounted（continuation 由 physics_frame 信号自持）；
## 壳亡/被顶号 → _alive() 假 → 静默让位，**不再有 resume-on-freed 路径**。
## mark_src 本任务**不消费**（判清登记仍留在壳 switch_segment 同步段的旧位，
## T1 逐位等价红线；T2 终裁后搬来此处）。
func _run(target: StringName, entry: StringName, why: StringName,
		revive: bool, _mark_src: StringName) -> void:
	for _i in 90:
		await _frame()
		if not _alive():
			return
	var shell := instance_from_id(_shell_id) as ChapterShell
	shell._live_enemies().map(func(e): e.queue_free())
	var waited := 0
	while shell._live_enemies().size() > 0 and waited < 120:
		await _frame()
		waited += 1
		if not _alive():
			return
	shell = instance_from_id(_shell_id) as ChapterShell
	if shell == null or _gen != shell._transition_gen:
		return   # I2 语义不变：最新意图胜出，本链连让位带解绑
	if revive:
		shell._revive_playable()
	shell.enter_segment(target, entry)
	if why != &"":
		shell.segment_restarted.emit(why)

func _alive() -> bool:
	var shell := instance_from_id(_shell_id) as ChapterShell
	return shell != null and _gen == shell._transition_gen

func _frame() -> void:
	await Engine.get_main_loop().physics_frame
```

等帧一律 `Engine.get_main_loop()`（SceneTree 单例），**不得**持 tree/壳的常驻引用（只存 instance id）。
