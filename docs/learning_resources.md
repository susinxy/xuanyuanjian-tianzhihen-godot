## 📖 学习技巧

### 阅读文档时
1. **先看示例代码**，理解最终效果
2. **理解核心概念**，不要死记硬背
3. **边学边做**，每看 10 分钟就动手实践

### 遇到问题时
1. **先查官方文档**（最权威）
2. **搜索引擎**（关键词 + Godot 4）
3. **社区提问**（描述清楚 + 附代码）
4. **问 AI**（可以让我帮你分析问题）

### 调试技巧
1. **使用 print 语句**：追踪变量变化
2. **查看 Godot 控制台**：错误信息很重要
3. **使用调试器**：F3 切换调试模式
4. **分步调试**：F10 单步执行
