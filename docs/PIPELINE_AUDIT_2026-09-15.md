## 三、T4 挂账（未做，各有归属）

1. **阵营粒度=个体、无"组"语义**：chen 与未来队友张烈 `area2d:` 互不相同=可互伤；
   法术只豁免施法者本人不豁免队友。**Phase 1（多角色入场）必踩**。
   → 列为"第一个可玩切片设计会"正式议题（友伤是否存在、组级阵营怎么建模）
2. **法术体真四向几何**：active 四文件现共用单一精灵序列 → 轮廓工具只能产 2 套几何，
   up/down 为 right 复制；真四向需美术分方向出帧 + spriteframes 分槽。→ 美术排期时定
3. **法术缩放/母版管线启用**（工具已同源，等真帧）。→ 同上
4. **两条 Run Test 模板深度合并**：暂以 parity 断言兜底，形态差异仍有合理性与观察价值。
   → 若未来两侧需求趋同再议
