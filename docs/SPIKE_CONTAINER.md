# 舞台容器原型备忘（spike，2026-09-21）

> 一次性耗材批：`tools/container_prototype/`（章节壳+两裸舞台内容件）**不进回归矩阵、
> 不承载施工**。目的：为 S2 切片设计会的"舞台容器/跨地点状态延续"议题产出**实测
> 底稿**——容器到底可不可行、贵在哪、设计要裁决什么。

## 一、正面结论（可行性，全部实测）

| # | 事实 | 含义 |
|---|---|---|
| E1/E2 | **裸舞台内容件**（无 base_stage 骨架，纯几何+三件套+光照件）在轻量章节壳下，锁房/刷怪/真死链清场全链路工作 | 骨架与内容的拆分线成立，内容层可完全数据化 |
| E3 | 摘树/挂树切换中，玩家永驻壳内 → **相机零改动**（本就是玩家子节点），落位即迁移完成 | "切舞台不重载"的物理基础白送 |
| E4 | **摘树不释放（常驻内存）= 清场持久机制本体**：回 A 房 `is_completed` 保持、零复活、无报错 | 章节内"打过房不重打"零额外系统 |
| E6 | 玩家属性跨切换天然延续（hp 原封） | 状态包最小版（角色本身）免费；扩展包内容=设计议题 |

## 二、负面结论（必须处理的裂缝，均有实测复现与对策原型）

| # | 裂缝 | 复现 | 对策（原型已验证/待施工） |
|---|---|---|---|
| C1 | **骨架五职责需升壳**：检查点注册、HUD+三壳、波次聚合解锁、ESC 接管、通关面板全在 BaseStage 上 | E7 静态盘点 | 容器施工主体量；舞台内容件保持零壳件 |
| C2 | **在途 Tween 孤儿炸 null**：锁房收口挂在 `tween.finished` 回调，摘树瞬间 get_tree()==null → SCRIPT ERROR | E3 首跑实锤（FightRoom._clamp_players_into_room:202） | 切换=静默窗（实测 90 帧落位）+待正式策略（取消 tween 或插件补防御，设计会选） |
| C3 | **尸体滞留**：死亡演出链数秒，摘树时实体仍在组内，随树迁移复挂 | E3/E4 二跑实锤 | 原型验证"切换即强清"（等待静置+queue_free）可行；**策略 A 强清（保持久）vs B 释放重建（弃持久）=设计会二选一** |
| C4 | **传送误触检测器**：入口若落在线东（含敌人落点区），落地即锁房开战、玩家被咬死 | E6 二跑 hp 71→0 实锤 | 容器入口点纪律：一律放检测线前场区；或显式"进房即战"标记=设计会顺带裁决 |
| C5 | **画布色残留**：CanvasModulate 随舞台摘树后全局留色；controller `_ready` 一次性语义（复挂不重跑 enter_scene） | E5 | 切换者负责复位（壳写 canvas 色）；"回旧舞台时间要不要续"=设计议题 |
| C6 | **R5 落位路径语义变化**：生成器 spawn 落位指向壳层 Players（本实验 `../../../Players`），validator R1-R10 全按单地点树写 | 通过（原型可用） | 双轨制裁决时 validator 同步（议题③） |

## 三、给 S2 设计会的四个待裁决议题

1. **状态包**：跨舞台延续只含角色本体（免费），还是含道具/任务/剧情旗（=会话状态中心，与 S5 存档同构设计）；
2. **离场清理策略**：C3 的 A（强清保持久）/B（释放弃持久）；
3. **单地点场景双轨制**：ref A/B 与未来小游戏关是否继续合法（推荐双轨：BaseStage=单地点退化形态，容器=章节形态）；
4. **光照时序**：C5 复位责任 + 玩家切回旧舞台时"时间"连续还是重定档。

## 四、总判定

**容器可行性高、非深渊**：迁移物理（玩家/相机/持久）实测白送，改造成本集中在
"骨架职责上移"（C1，一期内可完成的重构）与四条策略裁决。**不是要不要做的问题，
是设计会把四题拍完就施工**——维持既定序：容器=S2 切片施工第一批。
