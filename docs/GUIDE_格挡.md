## 0. 快速上手（三十秒）

1. **玩**：局内**点按 K**（格挡键）——角色架盾起手 → 自动收拳回待机。
2. **新角色**：Inspector 创建面板出生的角色**天生带全套格挡动画**（模板快照
   自带四件占位资产），零接线。
3. **三件不开代码就能改的事**：
   - 换姿势图 → `resources/sprites/block_out|block/` 同名覆盖（§2.2）
   - 调弹反/持盾时长 → 改动画 `length`（§2.4，改的就是战斗平衡）
   - 调火花观感 → `scripts/effects/presets/spark_parry.tres` / `spark_block.tres`（§4）

## 1. 机制原理（玩家视角）

### 1.1 点按序列制

按一次 K 启动一段**不可长按**的动画序列：

```
点按 K → block_out（起手段＝弹反窗，相位 OUT）
       →〔弹反成功了〕起手段余程放完后【直接收拳回 Idle】——R12 弹成即自由
       →〔没弹到〕  block（持盾段＝格挡窗，相位 GUARD）→ 收拳回 Idle
```

- **不支持长按**：按住 K 不会连架。本段序列收口后键还按着也**不起二段**，
  必须松手再点（起按边沿锁）。
- **序列中再按无效**：格挡进行中按 K 不重入、不倒退。
- 被受击/击飞/抓取打断时，三件套状态由同一出口清零，无残留（单写者宪章）。

### 1.2 弹反与格挡的待遇差

| 受击瞬间相位 | 名称 | 待遇 |
|---|---|---|
| OUT（起手段）+ 盾面对上来袭侧 | **弹反** | 免伤免退；攻击者被顶退进自己受击动画+罚站 6 拍（其攻击盒对**你**封形）；蓝白金属火花（parry 卡）；起手段余程放完即**直接收拳**（R12 跳持盾段）——**弹成=立即反击** |
| GUARD（持盾段）+ 同面 | **格挡** | 掉血 = 原伤害 × `block_damage_ratio`（默认 0.4）；击退值**整颗作废**（不扣抵抗池、不进入受击）；暗金闷挡火花（block 卡）；**序列保持继续**（挡下攻击不硬直） |
| 相位对但**面不对**（背面来袭） | —— | 按普通挨打：满伤、扣池、受击动画、default 火花（错面**不降级**为格挡） |

**防御经济学三档**（R12 后）：挨拳（满伤+被击退+动作被抢）＜ 格挡（掉 0.4 血、
不硬直但敌人活着能打你第二拳）≪ 弹反（零成本+敌人罚站挨打窗口+你收拳最快、
**弹成就夺回主动权**——正确玩法是弹完立刻打回去，不是再架盾）。

### 1.3 方向制：恒左右、x 一票制

- 格挡**只有左右两面**（与攻击朝向模式无关，恒水平）。
- 起手瞬间按"面朝"钉死盾面方向（面朝左=盾挡左侧来拳），**序列期不转头**。
- 来袭方向的判定是"受击接触点的 x 符号"：接触点在人物中线**左侧算左来、
  右侧算右来**（x 恰好相等的瞬间归右）。
- 由此产生的**已知设计语义**：从上/下来纵深打你的敌人，按其**横向偏移**
  归入左或右一侧——盾朝向对上就挡得住。"站对方向"是玩法，不是 bug；
  背后偷拳穿盾满伤，同理也是玩法。

### 1.4 攻击后摇取消进格挡

地面连段**攻击中/收招硬直**期间按 K 可以取消进格挡序列（进入白名单：
待机/行走/奔跑/地面三连段 Combo1/2/3）。**空中跳攻的后摇不可架**（有意的
排除——空中防御在本作不存在）。

### 1.5 起架的 2~4 拍视觉延迟（知情项）

- **弹反窗从按下 K 当帧就生效**（判定先行）；
- **姿势画面晚 2~4 拍才到位**——皮肤动画从当前状态经"idle 中枢"中转一跳
  （本仓动画树接线纪律，与攻击起手同款），所以你**看起来**比判定的你慢半拍；
- 攻击后摇取消进格挡时，"盾已举起"的总时长比点按形略宽（收招被截断、
  起架提前起算）。

觉得"判定期露馅"或"晚半拍碍眼"→ 记档到 F5 感官单，改延迟需回炉动画树
方案，**不是本 GUIDE 的可调项**。

### 1.6 动画即规则

**弹反窗长 = `block_out` 动画时长；持盾窗长 = `block` 动画时长；
未弹反序列总长 = 两段之和；弹反成功序列 = block_out 一段（R12 直返）。**
改动画就是改平衡——这是特性不是巧合（§2.4 有红线）。

## 2. 排产与换图

### 2.1 文件地图（每个角色目录内）

```
characters/<阵营包>/<名字>/resources/
├── sprites/block_out/right/block_out_right_00.png   ← 起手段贴图（右向）
├── sprites/block_out/left/block_out_left_00.png     ← 起手段贴图（见 §2.3 陷阱）
├── sprites/block/right/block_right_00.png           ← 持盾段贴图（右向）
├── sprites/block/left/block_left_00.png             ← 持盾段贴图（见 §2.3 陷阱）
├── animations/block_out_right.tres / block_out_left.tres   ← 时长+信标（§2.4）
├── animations/block_right.tres     / block_left.tres       ← 同上
├── spriteframes_<名字>.tres        ← 贴图登记表（加**新文件**才动）
├── anim_library_<名字>.tres        ← 动画登记表（同上）
└── animations/animation_tree_root.tres                     ← 动画树（勿手改）
```

占位现状：四张图都是**待机右向首帧的复制**（姿势=站桩），占位期"格挡看起来
像发呆"是预期内——真素材到货换图即愈。

### 2.2 换图 = 同名覆盖（标准流程）

1. 画好图，按**现行文件名**（含两位槽号 `_00`）盖进对应目录；
2. 打开 Godot 编辑器等底部扫盘/导入完成（外部改文件后编辑器需重扫；
   长时间开着的编辑器**建议重启**——吞改判例）；
3. 跑一次回归矩阵（§2.5 第 4 步）；
4. F5 进游戏按 K 目验姿势。

**多帧**：当前四件各 1 帧。要加第 2 帧起：新文件按槽号顺延（`_01`…），并在
`spriteframes_<名字>.tres` 给对应动画追加帧条目——这一步需要开tres文本，
属工程侧协助项，或等轮廓/动画工具开放补帧入口后再排。

### 2.3 ⚠ left 目录双面陷阱（本家族独有，必读）

`block`/`block_out` 是**全项目第一个真建了 `left/` 贴图目录**的动画家族
（idle/walk/hurt 等家族 left 目录不存在，左向=引擎拿右图翻面）。陷阱由此而来：

**现行机制：两张左向动画（`block_left.tres`/`block_out_left.tres`）内置
`flip_h=true`——最终画面 = left 目录图片的水平镜像。**

| 做法 | 结果 |
|---|---|
| ✅ **推荐（组合 A）**：left 目录放**未镜像的右向原图**（与 right 同源，或专门画一张右向的），引擎翻面成左向 | 正确，且与 hurt/idle 家族"flip 兜左"的语义一致 |
| ❌ 把右图**先自己镜像**再放进 left | 二次翻面——左向角色"背对"敌人摆姿势 |
| ⚠ 组合 B：left 目录坚持放**左向原图** | 必须**同时**打开两张左向动画 tres，把 `flip_h` 轨道键值 `[true]` 改成 `[false]` 才对（Godot 动画面板或文本改，**对新手属半开路径**——建议报工程侧代改，或干脆用组合 A）；只换图不改键=照样翻错 |

一句话记法：**"图的方向"和"动画里的 flip 键"加起来必须恰好翻一次面。**
当前默认键=已翻一次，所以 left 目录**放不翻面的原图**最省事。

### 2.4 调时序 = 调平衡（动画即规则的排产纪律）

可动零件只在这些位置：

- **弹反窗**：`animations/block_out_{left,right}.tres` 的 `length`（占位=0.2s=12 拍）
- **持盾窗**：`animations/block_{left,right}.tres` 的 `length`（占位=0.5s=30 拍）

**Godot 编辑器内操作路径**（无需文本编辑）：双击对应 `.tres` → Inspector 顶部
`Length` 数值框直接改（秒）；然后展开下方动画面板找到 `method` 轨道，把末帧
那枚呼叫 `end_of_skin_animation` 的方法键**拖到新 length 的结尾时刻**——
改 length 与方法键不同步=信标脱班（见下方生命线红线）。改毕 Ctrl+S。

改 `length` 时**必须同步**改同一文件里的**末帧方法轨**：`tracks` 里
`type = "method"` 那条的 `"times": PackedFloat32Array(0.2)` → 改成新的
length 值。这条方法轨呼叫 `end_of_skin_animation`，是序列推进的**生命线**：

> ⚠ **方法轨=生命线（断链=静默挂死）**：有槽但末帧信标缺失时，格挡序列会
> **永远停在起手段**——不崩、不报错，角色"架着盾冻住"，极难肉眼定位。
> 回归网 `block_parry_contract` P24b 会响红（案卷：R8 red_g 档），但请从
> 源头杜绝：**任何改 length / 加帧的手术，方法轨 key 时刻必须跟着挪到最后一帧。**

### 2.5 动画资产的两把时钟（换图/改帧数前必读）

每个皮肤动画由**两个文件两个数**共同决定，引擎不会自动同步它们：

| 时钟 | 存放处 | 数值 | 谁在消费 |
|---|---|---|---|
| **时段**（状态机占几秒） | `animations/<名>.tres` 的 `length` | 信标钉在时段末尾 | **玩法**：信标响=相位推进/状态收口（弹反窗=0.2s 即由此来） |
| **胶片**（图带子多长） | `spriteframes_*.tres` 该动画的 帧数 与 `speed`(fps) | 播放自然时长=帧数÷fps | **画面**：AnimatedSprite2D 自翻 |

**铁律：胶片时长必须 ≤ 时段（理想=恰好等于），否则动作被腰斩**——信标一到
状态就切走，胶片剩的帧永远没人看见（历史案底：施法起手 17 帧@5fps 挤 0.333s
时段=玩家只见 1.7 帧；本波全库对齐 18 处）。

- 你**换图/增删帧/在 SpriteFrames 面板改 speed** 之后：要么自己把
  `帧数÷speed` 调成 ≤length，要么直接把数字发给工程侧对齐；
- 矩阵哨兵：`editor_scripts_check` 会对**所有带信标的动画**检查
  "胶片放不完" 并响亮红（报错自带修法：fps 提至 X）；
- 反过来改 `length`（=改平衡）走 §2.4 全流程（方法轨随迁+契约备案）。

另外：占位四件的时长与"缺槽兜底常数"（12/30 拍）**刻意同数**，契约 P24d
锁死这层相等。你把 length 改成别的值后 P24d 会红——那不是让你顺手改常数，
而是提醒你**正在改战斗平衡**：先过设计裁决，再由工程侧同批改常数对。

### 2.5 产线与验证（涉及模板/新角色时）

1. 换的是**模板**（`templates/character/…`）→ 影响所有**未来**新生儿；
   换的是**某角色** → 只影响该角色。chen 与模板是**同文双写**的独立文件，
   改一边不自动传染另一边。
2. **禁止**全量跑 `tools/sync_template_from_chen.py` 来"对齐"——chen 已有
   内容侧漂移（attack1 图重编号等，实跑一次=92 文件无关改写）。定向覆盖
   目标文件即可。
3. 新角色的格挡件出生即有（模板克隆），无需任何面板操作。
4. 任何皮肤/动画面改动后跑：
   `bash tools/matrix_runner/run_matrix.sh`（内含 test_actor 销毁重建+26 跑）；
   只想快速单验格挡：`--ensure-only` 重建替身后单跑
   `godot --headless --path . res://tools/block_parry_contract/block_parry_contract.tscn`。

### 2.6 老皮肤 / 缺槽皮肤的行为

没带 block 四件的角色（B4.8 之前出生的老皮肤、或你把槽删了测试）：
格挡**照常可用**，时序改由兜底常数 12/30 拍说话，姿势=上一动作的冻结画面。
每次进入格挡会在输出面板告警一次：
`B4.8: 皮肤 <名字> 缺格挡动画槽，走兜底帧数时序`——这是提示不是错误。

## 3. 常见错误解读（症状 → 原因 → 处置）

| 症状 | 最可能原因 | 处置 |
|---|---|---|
| 按 K 没反应 | 键还按着没松（边沿锁）/ 在空中 / 正处于受击·击飞·另一段格挡中 | 松手再点；落地再架；打断恢复属设计 |
| 架盾后角色冻住不收拳（不崩） | **方法轨断链**（§2.4 生命线）——动画有槽但末帧信标缺失 | 对照 hurt 件补回 method 轨；跑 P24b 验证 |
| 明明"在挡"却满伤挨到 | 方向门生效：敌人在盾面**背面**一侧（含纵深偏 x 划到反侧） | 转身面向来袭侧再点 K；见 §1.3 |
| 弹反成功后"持盾段没了" | **设计如此（R12）**：弹成=立即收拳反击，GUARD 只属于弹空的人 | 弹完打回去；想再架盾=松手重按新一轮点按 |
| 弹反"该成功却没成功" | 受击瞬间已过弹反窗（=block_out length，默认仅 0.2s）或面不对 | 提前按（弹反窗从按下当帧生效）；或按 §2.4 走设计流程加长 |
| 空中拳/弹体也被我弹开了 | 设计如此：方向门只看接触点 x 符号，与攻击来源是地面/空中/弹体无关（弹体弹反有独立回归锁） | 非缺陷 |
| 姿势翻向错误（面向反了） | left 目录双面陷阱（§2.3） | 按组合 A 换不镜像原图，或按组合 B 连 flip 键一起改 |
| 换图后毫无变化 | 文件名/槽号不匹配、扫盘未完成、或长会话编辑器吞了外部改动 | 核对 §2.1 文件名；重启编辑器 |
| 矩阵 P24d 红 | length 与兜底常数不再同数 | **不要顺手改常数**——这是"平衡已被你改动"的报警器，走 §2.4 流程 |
| 输出面板 `B4.8: … 缺格挡动画槽` 告警 | 该皮肤无 block 槽（老角色/删槽） | 想接线：从模板复制四件+三张登记条目；不想接：无事，走兜底 |
| 长按 K 想一直架盾 | 本机制**不支持长按**（R1 裁决） | 节奏改法：每 ~0.7s 点一次，每次一整个序列 |

## 5. 本 GUIDE 的验收句

"新内容贡献者不开代码编辑器可完成本批解锁的内容类型"——逐项对账：
换姿势图 ✅ right 向零门槛（§2.2）；left 向推荐组合 A 同 ✅、组合 B（左向原图）**半开**（flip 键手术建议工程侧代改，§2.3）；调弹反持盾时长 ✅（§2.4 已补 GUI 路径：双击 tres 改 Length+动画面板挪方法键，含生命线自检）；
老皮肤接线状态判别 ✅（§2.6 告警语义）；火花观感调整 ✅（§4 卡路径）；
多帧补帧 ⚠ 半开（帧条目追加需工程协助，§2.2 已申报边界）。
